# dsc

Top level: dsc.doc(), commands, the scripts folder, errors.

## `help(...)`

Print a compact, always-current reference for the dsc API, built from the
live docstrings. help() lists the modules, classes and functions; a module or
class topic (help('ops.rigging'), help('Object')) lists its members as
name(args) with a one-line summary; a call topic
(help('ops.rigging.place_truss')) prints that call's full docstring;
help('conventions') summarises the units. The MCP 'docs' tool returns the same
text for clients that surface tools but not resources.
Example: dsc.help('ops.rigging')

## `register_command(label: str, fn: object) -> str`

Add a command to the Scripts menu. Running it calls fn() as one undo step named after the label. Call from a plugin's register(); the command isremoved when the plugin unloads. Returns the command id.Example: dsc.register_command('Number fixtures', number_fixtures)

## `unregister_command(command_id: str) -> bool`

Remove a command added with register_command. Returns False if it was not registered.

## `register_tool(tool: object) -> str`

Register an interactive tool: a dsc.Tool subclass (or an instance). It appears in the toolbox and behaves like a built-in tool. Call from a plugin's register(); it is removed when the plugin unloads. Returns the tool id.

Example: dsc.register_tool(MyLineTool)

## `unregister_tool(tool_id: str) -> bool`

Remove a tool added with register_tool. Returns False if it was not registered.

## `tools() -> list`

The ids of the script tools currently registered.

## `scripts_dir() -> str`

The user scripts folder (loose *.py scripts, plugin folders, modules/).

## `doc() -> dsc.Document`

The active document (shortcut for dsc.app.active_document(), raising if none).

## `object_types() -> dict`

{type name: describe()-style attribute list} for every drawing object type.

## `check(checks: object = None, scope: object = None) -> list`

Lint the drawing and return a list of findings so an agent can verify its
own work. Each finding is {kind, severity ('info'|'warning'|'error'),
message, objects (list of ids), location (x, y) mm or None}. `checks` is a
list of check names to run (default all); `scope` limits the per-canvas
checks to one canvas (a sheet name, doc.model_space or '*'; default the
whole document). Checks:
  overlapping_text      - data tags / text whose rendered boxes overlap
  text_overflow         - text taller than its fixed box (dsc.inspect.text_extents)
  dmx                   - DMX address clashes + unpatched fixtures
  empty_layers_classes  - empty layers/classes + objects with no/dangling layer
  fixtures_missing_data - fixtures whose GDTF has no power (wattage) or weight
  hoist_load            - per-hoist load vs its rated limit (Capacity/WLL),
                          using dsc.ops.rigging.runs(); info where weight is unknown
Example: [f for f in dsc.check() if f['severity'] == 'error']

## exception `ObjectGone`

Raised when a dsc.Object's object was deleted (by the script, the user or undo).

## exception `ReadOnlyError`

Raised when writing to a part generated by a composite, or an attribute Python cannot set.

## `add_line(x1: float, y1: float, x2: float, y2: float) -> str`

Add a line from (x1, y1) to (x2, y2), in mm with Y up. Returns the object id.

*Deprecated: Scripting 0 spike, kept for old scripts. Use dsc.ops.draw / Document.objects.*

## `count(type_name: str = '') -> int`

Number of objects in the document, optionally only those of one type name.

*Deprecated: Scripting 0 spike, kept for old scripts. Use dsc.ops.draw / Document.objects.*
