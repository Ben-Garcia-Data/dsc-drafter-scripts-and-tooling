# dsc.Object

Objects: attribute access, transform, typed Line / Circle / Text / Group / Layer / Class / Sheet (page setup) / Viewport / title blocks.

## class `Object`

One object in a document, held by id. Attributes are read and written with
obj['Name'] in public units (mm, plan Y up, degrees). If the object is
deleted (for example by undo) any access raises dsc.ObjectGone.
Most kinds (fixtures, truss, hoists, decks) are a plain dsc.Object or
dsc.Group in Python, so match on obj.type or doc.objects(type=...),
never isinstance() or type(obj).__name__.

### `id` (read-only)

Persistent id string (survives save/load).


### `exists` (read-only)

False once the object has been deleted.


### `type` (read-only)

Object kind, e.g. 'Line', 'LightingDevice', 'Hoist', 'RigMember'. Match on
this (or doc.objects(type=...)), not on the Python class.


### `name`

The object's name: its own Name (styles, title block parts and layouts,
departments), else its label.


### `read_only` (read-only)

True for parts generated by a composite (edit the composite instead).


### `source_file` (read-only)

The path of the file this object was imported from, or None for objects made
in the app. Set by import_file / File > Import, so you can find what a file
produced: doc.objects()  then filter on obj.source_file.


### `get(self: dsc.Object, attribute: str, default: object = None) -> object`

Read an attribute, or `default` when the object has none by that name.


### `attribute_names(self: dsc.Object) -> list[str]`

Every attribute name this object carries.


### `attributes(self: dsc.Object) -> dict`

All attributes as a dict (public units).


### `describe(self: dsc.Object) -> list`

One dict per attribute: name, unit, storage type, label/description/options when known.


### `layer`

The design layer (dsc.Layer). An equipment/composite object also moves its children onto it.


### `cls`

The class (dsc.Class). An equipment/composite object also moves its children onto it.


### `set_layer(self: dsc.Object, layer: object, children: bool = False) -> None`

Set the design layer (a dsc.Layer). An equipment/composite object
always moves its children onto the same layer; for a plain group
children=True opts into that (the plain obj.layer = ... on a group
leaves its children). Example:
    fixture.set_layer(doc.add_layer('Lighting'))


### `set_class(self: dsc.Object, cls: object, children: bool = False) -> None`

Set the class (a dsc.Class). An equipment/composite object always
moves its children onto the same class; for a plain group
children=True opts into that (the plain obj.cls = ... on a group
leaves its children).


### `visible`

Shown on the canvas (the object's own flag; layers and classes can also hide it).


### `locked`

Locked against selection and editing on the canvas.


### `location`

Origin (x, y, z) in mm, in the parent group's frame (world for top-level objects).


### `rotation`

Plan rotation in degrees, counter-clockwise.


### `world_location` (read-only)

Origin in world space (mm), through any parent groups.


### `material_color`

Solid colour override for the object's 3D mesh, as '#RRGGBB' / '#AARRGGBB'
(also settable as an int or (r, g, b[, a]); opaque unless you give alpha).
Set on every SceneObject3D part of the object; None = unset. The 3D render
honours it for imported models and standalone 3D meshes; a push/pull solid
also takes its colour from its 2D shape's fill. Raises if the object has no
3D mesh. This is a plain colour, not a full material (roughness/textures TBD).


### `emitted_color`

The fixture's emitted light colour as RGB ('#RRGGBB'), stored as CIE
xyY in the MVR colour slot (mvrColorXyY) so it round-trips through MVR
export/import. Accepts '#RRGGBB' / '#AARRGGBB' / int / (r, g, b).
None = unset. NOTE: the 3D viewport does not yet render emitted light
(beams), so today this drives MVR interchange, not the live render.
Only MVR fixtures (Lighting Device) carry the slot; other objects raise.


### `bounds` (read-only)

Plan bounding box (xmin, ymin, xmax, ymax) in world mm. A text reports its laid-out box (the extent the canvas draws), not just its insertion point.


### `bounds3d` (read-only)

The object's 3D bounding box in WORLD mm, or None when it has no 3D mesh.
A dict {'min': (x, y, z), 'max': (x, y, z), 'size': (w, d, h), 'center':
(x, y, z)} (plan Y up, Z up). Aggregates every SceneObject3D part of a
composite / group. Imported models report the bounds recorded at import
(both single-part and multi-part — each part carries its own authored AABB).


### `mesh_bounds` (read-only)

The mesh's AUTHORED / local 3D bounding box in mm (before the object's
location / rotation / scale) — the twin of the glTF accessor min/max — or
None. Same dict shape as bounds3d. For a leaf SceneObject3D (an imported
model part, a push/pull solid) it is the part's own mesh; for a group or
composite it is the union of all its parts' meshes in the group's own frame.


### `mesh_center` (read-only)

The centre (x, y, z) mm of the mesh's authored/local bounds (a group: of
all its parts, in its own frame), or None. The importer centres a model's
bounding box on the drop point, so this is where the geometry sits relative
to the object's own origin (see docs('conventions')).


### `pivot` (read-only)

The mesh's edit-origin offset (x, y, z) mm — the object's origin minus the
mesh's local origin — or None for a non-mesh object. Zero for a freshly
imported model; set when its origin has been moved (Set Origin).


### `parent` (read-only)

The group this object belongs to, or None.


### `move(self: dsc.Object, dx: object, dy: object = None, dz: object = None) -> None`

Move BY a delta (dx, dy, dz) mm. Accepts move(dx, dy[, dz]) or
move((dx, dy[, dz])). Use move_to(...) to move to an absolute point.


### `move_to(self: dsc.Object, x: object, y: object = None, z: object = None) -> None`

Move TO an absolute point: set the object's origin (its location) to
(x, y[, z]) mm, in the parent group's frame (world for a top-level object).
z is kept if omitted. Accepts move_to(x, y[, z]) or move_to((x, y[, z])).


### `rotate(self: dsc.Object, degrees: float, about: object = None) -> None`

Rotate counter-clockwise by `degrees` about `about` (x, y) mm, default the bounds centre.


### `rotate3d(self: dsc.Object, axis: object, degrees: float, about: object = None) -> None`

Rotate in 3D about `axis` ('x', 'y', 'z' or an (x, y, z) vector, public
orientation: X right, Y up/north, Z up) by `degrees` counter-clockwise seen
from the +axis, about the point `about` (x, y, z) mm — default the object's own
origin. Updates both the object's Rotation and Location so it pivots about the
point. Euler order matches the scene: the stored Rotation composes Z, then Y,
then X (Z-Y-X). rotate3d('z', d) is the plan rotation obj.rotate(d) does.
Example: coupler.rotate3d('x', 90, about=(0, 0, 1000))


### `duplicate(self: dsc.Object, *, canvas: object = None) -> object`

Copy the object in place; returns the copy. canvas= (a sheet, sheet name or
doc.model_space) puts the copy on that canvas instead of the active one.


### `delete(self: dsc.Object) -> None`

Delete the object (and a group's members).

## class `Sheet`

Subclass of `Object`.

A paperwork sheet (its canvas). Page setup reads and writes here; sizes are mm.
Draw on it with doc.on_canvas(sheet); add viewports with
dsc.ops.paperwork.create_viewport. Sheet coordinates: (0, 0) is the paper's
top-left and the paper runs down into negative Y.

### `name`

Sheet name, as the sheet list shows it.


### `size`

Paper size: 'A4', 'A3', 'A2', 'A1', 'A0', 'Letter', 'Legal', 'Tabloid' or
'Custom'. Set a (width, height) mm pair for a custom size.
Example: sheet.size = 'A1'; sheet.size = (600, 400)


### `orientation`

'portrait' or 'landscape'. Turning a custom size swaps its width and height.


### `width` (read-only)

Paper width in mm, orientation applied.


### `height` (read-only)

Paper height in mm, orientation applied.


### `margins`

(left, top, right, bottom) in mm; set one number for all four.


### `unit`

Display unit of the page setup: 'mm', 'cm' or 'in' (sizes stay mm here).


### `viewports` (read-only)

The viewports on this sheet (ObjectSet).


### `setup(self: dsc.Sheet, *, size: object = None, orientation: object = None, margins: object = None, unit: object = None) -> None`

Change several page-setup values at once (omitted = keep). Same values as the
properties.
Example: sheet.setup(size='A1', orientation='portrait', margins=15)


### `duplicate(self: dsc.Sheet, name: object = None) -> object`

Duplicate this sheet — its page setup, title block and every viewport / text /
shape on it — as a new sheet, and return it. `name` defaults to '<name> copy'.
One undo step.
Example: plot2 = doc.sheet('Sheet 1').duplicate('Sheet 2')


### `export_pdf(self: dsc.Sheet, path: str, dpi: int = 300) -> None`

Export this sheet to a PDF file at `path`, no dialog — the same output as
File > Export > PDF (title blocks in print mode). The sheet is written as
true vector geometry (crisp at any zoom, with selectable text); `dpi` sets
the resolution (72..2400, default 300), which fixes the cosmetic line
weights and any embedded rasters. A missing folder is created. GUI-host
only; raises in a headless run.
Example: doc.sheet('Sheet 1').export_pdf('C:/out/sheet1.pdf', dpi=300)


### `export_image(self: dsc.Sheet, path: str, *, width: int = 1920, height: object = None, background: object = 'white', quality: int = 90) -> str`

Export this sheet as a PNG or JPEG image (by the path's extension), no
dialog - the same output as File > Export > PNG / JPEG (title blocks in print
mode). The sheet is fitted into `width` x `height` pixels, centred; height=None
follows the sheet's aspect ratio. `background` is 'white' (default), 'black',
'transparent' (PNG only) or any colour. `quality` (1..100) is for JPEG. A
missing folder is created. Returns the written path. GUI-host only.
Example: doc.sheet('Sheet 1').export_image('C:/out/sheet1.png', width=3000)


### `render(self: dsc.Sheet, wait: bool = True) -> None`

Render the active sheet's viewports and, with wait=True (default), block until
done — so a following screenshot is not caught mid-render. A sheet screenshot
already forces a synchronous render, so this is mostly for pre-warming.


## class `Viewport`

Subclass of `Object`.

A paperwork viewport — a masked window into the design on a sheet, made by
dsc.ops.paperwork.create_viewport. frame_size resizes the paper frame;
set_layer_visibility / set_class_visibility / set_department_visibility change
the per-viewport overrides; SourceScale / SourceCenter (obj[...]) pan and
rescale. A 3D viewport also carries CameraYaw / CameraPitch / CameraDistance.

### `frame_size`

The paper frame size (width, height) in mm. Setting it makes a RECTANGULAR
frame of that size (clearing any custom crop shape). Example:
    vp.frame_size = (180, 120)


### `set_layer_visibility(self: dsc.Viewport, visibility: object) -> None`

Set the per-viewport DESIGN-LAYER visibility, a dict {layer: 'visible' |
'grey' | 'hidden'} (or 0..1) — the same form create_viewport(layers=...) takes.
Keys are a dsc.Layer, its id or its name. Replaces the whole map.
Example: vp.set_layer_visibility({'Dimensions': 'hidden'})


### `set_class_visibility(self: dsc.Viewport, visibility: object) -> None`

Set the per-viewport CLASS visibility, a dict {class: 'visible' | 'grey' |
'hidden'} (keys a dsc.Class, id, name or dashed path). Replaces the whole map.


### `set_department_visibility(self: dsc.Viewport, visibility: object) -> None`

Set the per-viewport DEPARTMENT visibility, a dict {department: 'visible' |
'grey' | 'hidden'}. Replaces the whole map.


### `render(self: dsc.Viewport) -> None`

Render this viewport now and wait for it. A 3D viewport only renders while its
sheet is active, so use this (or dsc.app.wait_idle()) before a screenshot. A
sheet screenshot already forces a synchronous render, so it is rarely needed.


## class `TitleBlock`

Subclass of `Group`.

A sheet's title block instance (returned by assign_title_block). It is a
generated composite — refresh() rebuilds it after you edit its layout's parts
or the project fields, so you don't have to unassign and reassign the layout.

### `refresh(self: dsc.TitleBlock) -> None`

Rebuild this title block from its layout and the current field values —
the same rebuild assigning the layout performs. Call it after editing a
part's texts (layout.part(name).texts) or ProjectInfo fields.
Example: tb = dsc.ops.paperwork.assign_title_block(layout, sheet='Sheet 1'); tb.refresh()


## class `Layout`

Subclass of `Object`.

A title block layout — the arrangement of title-block parts. part(name) returns
the part in a named slot so you can read/edit its texts.

### `part(self: dsc.Layout, name: str) -> object`

The part (a dsc.TitleBlockPart) placed in the slot with this id, or None if
the slot is empty. Slot ids are the 'id' values from title_block_layout().


### `slots` (read-only)

The slot ids in this layout (for part()).


## class `TitleBlockPart`

Subclass of `Object`.

A title block part (an Asset placed in a layout slot). texts lists its editable
Text objects, so a script can change a part's labels without hunting for the
source text by content. Edit a text's .html / .text, then TitleBlock.refresh().

### `texts` (read-only)

The part's Text objects (dsc.Text), in order — editable via .html / .text.


### `name` (read-only)

The part's name.
